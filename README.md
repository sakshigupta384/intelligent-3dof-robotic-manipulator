# 3-DOF Robotic Manipulator with Inverse Kinematics and Telemetry

An educational robotics project focused on inverse kinematics, 3D visualization, interactive motion control, and telemetry monitoring.

## Project Modules

- `inverse_kinematics.py` – Inverse kinematics calculations.
- `robot_3d.py` – 3D robotic arm visualization.
- `interactive_robot.py` – Interactive robot control.
- `serial_sender.py` – Serial communication.
- `serial_test.py` – Serial communication testing.
- `telemetry_dashboard.py` – Telemetry dashboard.

## Technologies Used

- Python
- Arduino / Tinkercad
- Streamlit
- 3D Visualization

## Project Objectives

1. Develop a 3-DOF robotic manipulator.
2. Implement inverse kinematics.
3. Visualize robotic arm movements in 3D.
4. Monitor joint movement and telemetry data.
